# Домашнее задание --- AI-планировщик обучения

## Что нужно сделать

Создать **Telegram-бота для обучения и подготовки к экзаменам**.

Обязательные технологии:

-   Python
-   aiogram
-   PostgreSQL
-   async/await
-   FSM
-   Reply Keyboard
-   Inline Keyboard
-   Callback Query
-   AI API
-   обработка PDF
-   планировщик уведомлений
-   Git + GitHub

## 1. Роли

Сделать 2 роли:

-   **Student**
-   **Admin**

## 2. Администратор

Администратор должен уметь:

-   создавать учебную программу;
-   загружать PDF;
-   извлекать текст из PDF;
-   делить текст на части (chunks);
-   отправлять части текста в AI;
-   получать от AI темы и подтемы;
-   сохранять темы в PostgreSQL;
-   просматривать, изменять и удалять темы;
-   активировать/деактивировать программу;
-   смотреть студентов и их прогресс.

Для каждой темы хранить:

-   `title`
-   `description`
-   `topic_order`
-   `difficulty`
-   `estimated_minutes`

## 3. Студент

Студент должен уметь:

-   зарегистрироваться;
-   выбрать учебную программу;
-   указать цель обучения;
-   указать дату экзамена;
-   выбрать дни занятий;
-   выбрать время занятий;
-   выбрать длительность занятия;
-   указать свой уровень;
-   получить персональный план от AI;
-   открыть сегодняшний урок;
-   переносить или пропускать урок;
-   задавать AI вопросы по текущему материалу;
-   проходить тесты;
-   отвечать на открытые вопросы;
-   писать краткое резюме урока;
-   смотреть прогресс;
-   смотреть слабые темы;
-   проходить пробный экзамен;
-   смотреть готовность к экзамену.

## 4. Персональный план

Через FSM спросить у студента:

1.  Цель обучения.
2.  Дату экзамена / дедлайн.
3.  Количество учебных дней в неделю.
4.  Дни недели.
5.  Длительность занятия.
6.  Время занятия.
7.  Текущий уровень.
8.  Подтверждение.

AI должен составить план с учетом:

-   тем;
-   порядка тем;
-   сложности;
-   доступного времени;
-   даты экзамена;
-   уровня студента;
-   предыдущих результатов.

Добавить повторение, практику и подготовку к экзамену.

## 5. Урок

На каждый учебный день создавать отдельную учебную сессию.

В уроке должны быть:

-   тема;
-   время;
-   материал;
-   задания;
-   вопросы к AI;
-   тест;
-   открытый вопрос;
-   краткое резюме.

Урок считать завершенным только после выполнения необходимых заданий.

## 6. Уведомления

Сделать автоматические уведомления о занятиях.

Можно использовать **APScheduler**.

Если урок пропущен:

-   отметить его как пропущенный;
-   предложить пройти сегодня;
-   перенести на свободный день;
-   перестроить учебный план.

Завершенные уроки при перестроении плана не удалять.

## 7. AI-репетитор

При вопросе студента передавать AI:

-   текущую учебную программу;
-   текущую тему;
-   текущий урок;
-   подходящие chunks из PDF.

AI должен отвечать на основе загруженного учебного материала.

## 8. Тесты и проверка знаний

AI должен создавать:

-   вопросы с вариантами ответа;
-   открытые вопросы.

Сохранять вопросы, ответы и результаты в PostgreSQL.

AI должен проверять открытые ответы и резюме студента.

## 9. Прогресс

Считать из PostgreSQL:

-   завершенные уроки;
-   пропущенные уроки;
-   средний результат тестов;
-   время обучения;
-   общий процент прогресса;
-   слабые темы.

План должен адаптироваться при:

-   пропущенных уроках;
-   плохих результатах;
-   сложных темах;
-   изменении расписания;
-   слишком быстром прогрессе.

## 10. Отчеты

Сделать:

-   еженедельный отчет;
-   ежемесячный отчет;
-   пробный экзамен;
-   показатель готовности к экзамену.

Создать минимум следующие таблицы:

``` text

study_plans
study_plan_days
lesson_tasks
```

### Основные связи

``` text

  ↓

  ↓
study_plan_days
  ↓

```

``` text

  ├── material_chunks
  └── topics
        ↓
    quiz_questions
```

``` text

  ├── quiz_attempts
  └── student_answers
```

Использовать:

-   Primary Key;
-   Foreign Key;
-   INSERT;
-   SELECT;
-   UPDATE;
-   DELETE;
-   JOIN;
-   GROUP BY;
-   WHERE;
-   ORDER BY;
-   агрегатные функции.

Минимум один настоящий отчет должен использовать **JOIN + GROUP BY**.

## 12. FSM и Telegram-интерфейс

FSM использовать минимум для:

### Настройки плана

``` text
Цель
→ Дата экзамена
→ Количество дней
→ Дни недели
→ Длительность
→ Время
→ Уровень
→ Подтверждение
```

### Добавления материала администратором

``` text
Название
→ Описание
→ PDF
→ Подтверждение
```

Использовать:

-   `StatesGroup`
-   `State`
-   `FSMContext`
-   `set_state()`
-   `update_data()`
-   `get_data()`
-   `clear()`

Обязательно использовать **Reply Keyboard** и **Inline Keyboard**.

## 13. Ошибки и безопасность

Обработать:

-   неправильный PDF;
-   поврежденный PDF;
-   PDF без текста;
-   ошибку AI API;
-   неправильный ответ AI;
-   ошибку PostgreSQL;
-   неправильную дату;
-   отсутствие темы;
-   отсутствие плана;
-   попытку обычного пользователя открыть Admin;
-   неправильный callback.

Секреты хранить в `.env`:

``` env
BOT_TOKEN=...
DATABASE_URL=...
AI_API_KEY=...
```

Не загружать в GitHub:

``` text
.env
.venv/
__pycache__/
```

## Итог

Готовый проект должен работать по цепочке:

``` text
Admin загружает PDF
→ текст извлекается
→ делится на chunks
→ AI создает темы
→ темы сохраняются в PostgreSQL
→ Student выбирает программу
→ настраивает расписание
→ AI создает учебный план
→ бот отправляет уроки и уведомления
→ Student проходит задания и тесты
→ результаты сохраняются
→ бот считает прогресс и слабые темы
→ план адаптируется
→ формируются отчеты и готовность к экзамену
```
