# Итоговый экзаменационный проект — AI-планировщик обучения и бот для подготовки к экзаменам

## 1. Цель проекта

Создать Telegram-бота, который превращает PDF-книгу или учебный документ в персонализированную программу обучения.

Бот должен работать как:

- ИИ-репетитор;
- планировщик обучения;
- помощник по подготовке к экзаменам;
- система отслеживания прогресса обучения.

Администратор загружает PDF-книгу. Бот извлекает и анализирует материал с помощью ИИ, определяет темы и подтемы и сохраняет структуру в PostgreSQL.

Студент выбирает учебную программу, указывает цель и расписание занятий и получает персонализированный план обучения. Во время обучения бот отправляет напоминания о занятиях, открывает ежедневные уроки, отвечает на вопросы с помощью ИИ, генерирует тесты, проверяет открытые ответы и конспекты, находит слабые темы и адаптирует план обучения.

Бот можно использовать для:

- подготовки к вступительным экзаменам в университет;
- школьных экзаменов;
- сертификационных экзаменов;
- изучения книг по программированию;
- изучения языков;
- университетских предметов;
- долгосрочного самостоятельного обучения.

Обязательные технологии:

- Python
- aiogram
- PostgreSQL
- асинхронное программирование
- FSM
- Reply Keyboard
- Inline Keyboard
- Callback Query
- AI API
- обработка PDF
- запланированные уведомления
- Git и GitHub

## 3. Загрузка PDF и анализ с помощью ИИ

Администратор должен иметь возможность загрузить PDF непосредственно в Telegram.

Пример процесса:

```text
Панель администратора
→ Создать программу
→ Ввести название
→ Ввести описание
→ Загрузить PDF
→ Запустить анализ ИИ
```

Бот должен:

1. проверить, что файл является PDF;
2. скачать файл;
3. извлечь текст из PDF;
4. разделить текст на небольшие части (chunks);
5. проанализировать все части с помощью ИИ;
6. объединить результаты ИИ;
7. определить главы, темы и подтемы;
8. оценить сложность и время изучения;
9. сохранить результаты в PostgreSQL.

Большую книгу нельзя отправлять ИИ одним огромным промптом.

Рекомендуемый процесс обработки:

```text
PDF
↓
Извлечь текст
↓
Очистить текст
↓
Разделить на части
↓
Проанализировать части
↓
Объединить результаты
↓
Создать темы
```

Для каждой созданной темы необходимо сохранять как минимум:

```text
title — название
description — описание
topic_order — порядок темы
difficulty — сложность
estimated_minutes — примерное время в минутах
```

Администратор должен иметь возможность просмотреть и исправить темы, созданные ИИ, до активации учебной программы.

## 4. Персональный учебный план

Перед созданием плана обучения бот должен задать студенту несколько вопросов.

Обязательные вопросы:

```text
Какова ваша цель обучения?
Когда ваш экзамен или крайний срок?
Сколько дней в неделю вы можете заниматься?
Какие дни недели вы предпочитаете?
Сколько времени вы можете заниматься за одну сессию?
В какое время вы хотите заниматься?
Какой у вас текущий уровень?
```

Дополнительный необязательный вопрос:

```text
Как вы предпочитаете учиться?
- Больше чтения
- Больше практики
- Больше тестов
- Сбалансированно
```

Пример:

```text
Цель:
Подготовиться к вступительному экзамену в университет

Дата экзамена:
20 февраля 2027

Дни занятий:
Понедельник, среда, пятница

Время занятий:
19:00

Длительность занятия:
2 часа

Уровень:
Средний
```

План обучения должен создаваться с учетом:

- всех тем из книги;
- порядка тем;
- сложности тем;
- зависимостей между темами;
- даты экзамена или крайнего срока;
- количества доступных недель;
- выбранных дней недели;
- длительности занятия;
- текущего уровня студента;
- предыдущих результатов студента, если они есть.

План обучения не должен просто делить все темы поровну.

Сложные или важные темы могут требовать больше времени. Также должны быть включены занятия для повторения и практики.

Пример:

```text
Неделя 1

Понедельник
Переменные и типы данных
90 минут

Среда
Операторы и ввод данных
120 минут

Пятница
Условия
120 минут
```

При подготовке к экзамену финальный период должен включать:

- повторение слабых тем;
- смешанные тесты;
- практические тесты;
- пробные экзамены;
- финальное повторение.

## 5. Ежедневная учебная сессия

На каждый запланированный учебный день должна быть создана учебная сессия.

Пример:

```text
Сегодняшний урок

Тема:
Функции Python

Время:
19:00 - 21:00

Задания:
1. Прочитать страницы 84-96
2. Изучить синтаксис функций
3. Изучить параметры и аргументы
4. Выполнить примеры
5. Задать вопросы ИИ
6. Пройти итоговый тест
7. Написать краткое резюме
```

Кнопки:

```text
[ Начать урок ]
[ Перенести ]
[ Пропустить сегодня ]
```

Урок не должен считаться завершенным только потому, что студент его открыл.

Например:

```text
Урок открыт
+
Тест пройден
+
Краткое резюме отправлено
=
Урок завершен
```

## 6. Уведомления и пропущенные уроки

Бот должен автоматически уведомлять студента о запланированных уроках.

Пример напоминания:

```text
Ваша учебная сессия начнется через 15 минут.

Тема:
Функции Python

Длительность:
2 часа
```

Во время начала урока:

```text
Пора заниматься.

[ Начать урок ]
```

В проекте необходимо использовать планировщик, например APScheduler или другой подходящий инструмент.

Если студент пропустил урок, он должен быть отмечен как пропущенный.

Бот должен предложить:

```text
[ Заняться сегодня ]
[ Перенести на следующий свободный день ]
[ Перестроить план обучения ]
```

Завершенные уроки не должны удаляться при изменении плана обучения.

## 7. ИИ-репетитор

Во время активного урока студент может задавать ИИ вопросы.

Пример:

```text
Зачем в Python используется return?
```

ИИ по возможности должен отвечать, используя текущую книгу и материал урока.

Бот должен передавать ИИ:

- текущую книгу;
- текущую тему;
- текущий урок;
- релевантные части текста.

В простой реализации можно искать части текста по теме или ключевым словам.

В продвинутой реализации можно использовать embeddings или pgvector, но это необязательно.

Студент должен понимать, как выбирается релевантный материал перед отправкой вопроса ИИ.

## 8. Оценивание урока

После урока студент должен выполнить как минимум одно или несколько из следующих заданий:

1. Тест с вариантами ответов
2. Открытый вопрос
3. Краткое резюме урока

### Тест, созданный ИИ

ИИ должен генерировать вопросы из материала текущего урока.

Пример:

```text
Что делает ключевое слово return?

A. Останавливает Python
B. Возвращает значение из функции
C. Создает переменную
D. Импортирует модуль
```

Вопрос и результат должны сохраняться в PostgreSQL.

### Открытый вопрос

Пример:

```text
Объясните разницу между параметром и аргументом.
```

Студент пишет ответ.

ИИ оценивает:

- правильность;
- полноту;
- недостающую информацию;
- понимание темы.

Пример:

```text
Оценка: 8/10

Хорошо:
Вы правильно объяснили основную разницу.

Что повторить:
Добавьте пример вызова функции.
```

### Краткое резюме студента

Бот спрашивает:

```text
Напишите кратко, что вы сегодня изучили.
```

ИИ проверяет:

- понимание;
- важные концепции;
- неправильные утверждения;
- пропущенные концепции;
- ясность изложения.

Резюме и обратная связь ИИ должны сохраняться в PostgreSQL.

## 9. Прогресс и адаптивный план обучения

Система должна рассчитывать прогресс на основе реальных данных из базы данных.

Панель студента может показывать:

```text
Завершенные уроки: 18 / 25
Средний результат тестов: 82%
Общее время обучения: 34 часа
Прогресс плана обучения: 72%
```

Бот должен определять слабые темы.

Пример:

```text
Слабые темы

1. SQL JOIN — 48%
2. Функции — 61%
3. ООП — 64%
```

ИИ должен уметь рекомендовать дополнительное повторение.

Пример:

```text
Ваш результат по SQL JOIN низкий.

Рекомендация:
Добавьте одно дополнительное занятие для повторения на этой неделе.
```

План обучения должен адаптироваться, когда:

- студент пропускает несколько уроков;
- результаты тестов низкие;
- тема сложная;
- студент изменяет расписание занятий;
- студент продвигается быстрее, чем ожидалось.

Пример:

```text
Ваш текущий план может больше не соответствовать дате экзамена.

[ Перестроить план обучения ]
[ Оставить текущий план ]
```

## 10. Недельная, месячная и экзаменационная аналитика

Бот должен формировать еженедельный отчет.

Пример:

```text
Еженедельный отчет

Завершено:
4 / 5 уроков

Время обучения:
8 часов

Средняя оценка:
81%

Сильные темы:
Переменные
Условия

Слабая тема:
Циклы
```

Для долгосрочных учебных планов бот также должен показывать месячный прогресс.

Пример:

```text
Август

Запланировано уроков: 18
Завершено: 16
Пропущено: 2
Средняя оценка: 84%
План выполнен: 28%
```

При подготовке к экзамену бот должен показывать готовность к экзамену.

Пример:

```text
Готовность к экзамену

План выполнен: 78%
Средний уровень знаний: 82%
Пробный экзамен: 76%
Регулярность занятий: 88%

Готовность: 79%
```

Этот показатель является образовательной оценкой. Студент должен уметь объяснить, как он рассчитывается.

Бот также должен поддерживать как минимум один пробный экзамен перед настоящим экзаменом.

## 13. Обработка ошибок и безопасность

Проект должен обрабатывать распространенные ошибки:

- неверный формат PDF;
- поврежденный PDF;
- PDF без читаемого текста;
- ошибка AI API;
- некорректный ответ ИИ;
- ошибка базы данных;
- некорректная дата;
- отсутствующая тема;
- отсутствующий план обучения;
- несанкционированный доступ администратора;
- некорректные callback-данные.

Секретные данные должны храниться в `.env`.

Пример:

```env
BOT_TOKEN=...
DATABASE_URL=...
AI_API_KEY=...
```

Следующее нельзя загружать на GitHub:

```text
.env
.venv/
__pycache__/
```

## 18. Итоговый ожидаемый процесс

### Администратор

```text
Создать программу
→ Загрузить PDF
→ Извлечь текст
→ Разделить текст
→ ИИ анализирует книгу
→ ИИ создает темы
→ Администратор проверяет темы
→ Активировать программу
```

### Студент

```text
/start
→ Зарегистрироваться
→ Выбрать программу
→ Ввести цель
→ Ввести дату экзамена
→ Выбрать дни занятий
→ Выбрать длительность занятия
→ Выбрать время занятий
→ Выбрать уровень
→ ИИ создает план обучения
→ Получить ежедневное напоминание
→ Начать урок
→ Изучить материал
→ Задать вопрос ИИ
→ Пройти тест
→ Ответить на открытый вопрос
→ Написать краткое резюме
→ ИИ оценивает результаты
→ Прогресс обновляется
→ Определяются слабые темы
→ План обучения адаптируется
→ Еженедельные / ежемесячные отчеты
→ Пробный экзамен
→ Готовность к экзамену
```

Итоговый результат должен ощущаться как настоящий образовательный продукт, а не просто набор Telegram-команд.

Студент должен продемонстрировать понимание:

```text
Разработка Telegram-ботов
+ Python
+ Асинхронное программирование
+ PostgreSQL
+ SQL
+ FSM
+ ИИ
+ Обработка PDF
+ Планирование задач
+ Git
+ GitHub
+ Архитектура проекта
```

Студент должен не только сделать проект рабочим. Он должен уметь объяснить, **как и почему он работает**.
