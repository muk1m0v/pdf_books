# AI Study Planner Bot

Telegram bot project for an AI study planner: it can accept learning materials, build a study plan, run lessons, quizzes, reminders, and progress tracking.

## Run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Required environment variables are stored in `.env`.
