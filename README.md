# 🚀 AI Study Planner Bot (Telegram Bot)

Учебный Telegram-бот для подготовки к экзаменам и управления процессом обучения. Проект разработан на фреймворке **aiogram 3.x**, использует **PostgreSQL** в качестве основной базы данных и подключается к **AI API (Groq / OpenAI)** для генерации персональных планов обучения, проведения тестов и ответов на вопросы студентов.

## 🎯 Возможности и функционал

### 👑 Для Администратора:
* **Загрузка и обработка PDF:** загрузка учебных материалов, извлечение текста и деление на смысловые фрагменты (чанки).
* **Управление программами:** автоматическое создание тем и подтем с помощью AI, редактирование, удаление и активация курсов.
* **Мониторинг:** просмотр списка студентов и их текущего прогресса.

### 🎓 Для Студента:
* **Интерактивная регистрация (FSM):** настройка цели, даты экзамена, количества учебных дней в неделю, времени и исходного уровня знаний.
* **Персональный учебный план:** генерация расписания с помощью AI с учётом дедлайнов и уровня сложности.
* **Ежедневные уроки:** прохождение теоретического материала, сдача тестов, ответы на открытые вопросы и написание резюме урока.
* **AI-Репетитор:** возможность задавать вопросы по материалу урока прямо в боте.
* **Адаптивность и статистика:** автоматический перерасчёт плана при пропуске уроков, определение слабых тем и расчёт готовности к экзамену.

## 🛠 Технологии

* **Python 3.10+** — основной язык разработки.
* **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API (Router, FSMContext, Keyboards).
* **PostgreSQL + asyncpg** — надежная реляционная база данных с асинхронным драйвером.
* **Groq API / OpenAI API** — нейросетевой модуль для обработки текста и составления планов.
* **pypdf** — извлечение и обработка текста из PDF-документов.
* **python-dotenv** — управление конфигурацией и секретными ключами.
* **colorama** — цветное логирование событий в консоли.

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/ai_study_bot.git
cd ai_study_bot
```

### 2. Создание и активация виртуального окружения
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка файла `.env`
Создайте файл `.env` в корневой директории и заполните его данными (см. раздел ниже).

```bash
python main.py
```

## 🗄 Архитектура Базы Данных

Проект использует 13 таблиц с четкими связями (`FOREIGN KEY`) и каскадным удалением данных:

1. `users` — пользователи (студенты и админы).
2. `learning_materials` — загруженные курсы и PDF-файлы.
3. `material_chunks` — фрагменты текста из PDF для передачи в AI.
4. `topics` — темы и подтемы курса.
5. `study_plans` — персональные учебные планы студентов.
6. `study_plan_days` — конкретные запланированные дни занятий.
7. `lesson_tasks` — задания к каждому уроку (чтение, тест, открытый вопрос).
8. `quiz_questions` — банк тестовых вопросов.
9. `quiz_attempts` — история прохождения тестов.
10. `student_answers` — ответы студентов на открытые вопросы.
11. `lesson_summaries` — краткие резюме уроков от студентов.
12. `topic_progress` — процент освоения темы и метка слабых тем.
13. `mock_exams` — результаты пробных экзаменов и готовность к защите.

## 🛡 Подготовка к защите (Ответы на вопросы)

* **Зачем разделять PDF на чанки (chunks)?**  
  *Ответ:* AI-модели имеют ограничение на объем входного текста (контекстное окно). Разделение PDF на небольшие блоки позволяет передавать только нужную часть материала при ответе на конкретный вопрос пользователя.

* **Как работает FSM в проекте?**  
  *Ответ:* FSM (Finite State Machine) фиксирует текущий шаг пользователя (например, ввод цели -> дата экзамена -> время). Данные накапливаются в `FSMContext` через `update_data()`, а в конце сохраняются в PostgreSQL.

* **Где используется SQL JOIN?**  
  *Ответ:* В отчете о прогрессе студента мы объединяем таблицы `users`, `study_plans`, `study_plan_days` и `quiz_attempts` с помощью `LEFT JOIN` и группируем результаты по `telegram_id` через `GROUP BY`.
