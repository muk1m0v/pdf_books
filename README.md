# PDF Books Bot

Telegram-бот на aiogram 3, который принимает PDF-книги, сохраняет их текст в PostgreSQL
и отвечает на вопросы по содержимому книги через бесплатный Google Gemini API.

## ⚠️ Важно про безопасность

Токен бота и пароль от БД, которые были в переписке, нужно **обязательно сменить**:
- Токен: у @BotFather команда `/revoke` (или `/token`), получи новый.
- Пароль Postgres: смени, если использовался где-то ещё.

Никогда не отправляй `.env` или реальные токены в чаты, репозитории и т.д.

## Установка

1. Установи PostgreSQL и создай базу:
   ```sql
   CREATE DATABASE pdf_books;
   ```

2. Клонируй/скопируй проект, установи зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate   # на Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Скопируй `.env.example` в `.env` и заполни своими значениями:
   ```bash
   cp .env.example .env
   ```

4. Получи бесплатный ключ Gemini API:
   - Зайди на https://aistudio.google.com/apikey
   - Войди через Google-аккаунт
   - Нажми "Create API key"
   - Вставь ключ в `.env` как `GEMINI_API_KEY`
   
   (Бесплатный лимит на 2026 год достаточен для учебного проекта; если лимиты изменятся —
   в коде `ai_service.py` легко заменить URL/модель на другой провайдер, например Groq.)

5. Запусти бота:
   ```bash
   python main.py
   ```

## Как пользоваться

1. `/start` — регистрация
2. Пришли PDF-файл документом — бот извлечёт текст и сохранит в БД
3. Пиши вопросы обычным текстом — бот ответит на основе содержимого книги
4. `/mybooks` — список твоих книг
5. `/use <номер>` — переключиться на другую книгу для вопросов

## Структура проекта

```
pdf_books_bot/
├── main.py            # точка входа
├── config.py           # переменные окружения
├── database.py         # работа с PostgreSQL (asyncpg)
├── ai_service.py        # запросы к Gemini API
├── pdf_utils.py        # извлечение текста из PDF
├── handlers/
│   ├── start.py        # /start, /help, /mybooks, /use
│   ├── upload.py        # приём PDF
│   └── qa.py           # обработка вопросов
├── requirements.txt
└── .env.example
```

- Ограничение размера загружаемого PDF
